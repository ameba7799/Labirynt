# Labirynt

Moim pomysłem na projekt jest gra - labirynt.
- [ ] Gra polega na przejściu kulką z punktu startowego do wyjścia.
- [ ] Automatycznie generowany labirynt z dokładnie 1 rozwiązaniem.
- [ ] Po dotarciu do wyjścia przechodzi się do kolejnego labiryntu.
- [ ] Labirynt najprawdopodobniej reprezentowany jako tablica z zaznaczonymi kierunkami w które można się z danego pola przesunąć lub drzewo w którem kolejne rozgałęzienia oznaczają ścieżki którymi można pójść.
- [ ] Poruszanie się za pomocą strzałek.
- [ ] Jak mi starczy czasu - okienko w którym widać tylko część labiryntu, przesuwające się po pulpicie przy zmianie pozycji kulki.
